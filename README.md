## PDFs kaise daalein

Bas ye 2 files `data/` folder mein rakho:

```
ssb_practice_tool/
└── data/
    ├── ppdt.pdf    ← 100 PPDT pictures (1 PDF)
    └── tat.pdf     ← 100 TAT pictures (1 PDF)
```

## Kya karta hai tool

- **No writing box** — aap apne paper pe likhte ho
- Exact SSB timing
- Picture time khatam → **START WRITING** + timer
- Time over → **🔔 BELL + STOP**

### PPDT
30 sec observe → START WRITING (1 min Character Box) → 4 min Story → 🔔 STOP

### TAT
12 pictures × (30 sec view → START WRITING 4 min) → 🔔 STOP

## Run
```bash
cd ssb_practice_tool
pip install -r requirements.txt
streamlit run app.py
```
